# 不买账实验室 · Lost Demand Lab

从消费表达识别购买阻力，提出沉默群组的研究假设，以最小实验探索增长机会。

**[在线体验 Demo](https://chrisghubhub.github.io/lost-demand-lab/)** · [GitHub 源码](https://github.com/chrisghubhub/lost-demand-lab)

这是用于作品展示的交互式静态 Demo，版本 **v0.9.6**。本次发布使用作者提供的 `不买账实验室_RedCodework单文件版_v0.9.6.html`，将其原样命名为 `index.html`，没有改动业务逻辑。此版本不包含后续讨论中的 P0/P1 规则评分改造。

> 所有评论、群组、搜索信号、浏览、加购和成交数值均为合成演示数据。没有连接小红书后台，没有实时大模型调用，也没有真实商业实验结果。案例灵感与演示数据应分开理解。

## 功能

- **购买阻力地图**：浏览购买阻力主题、查看合成评论证据、比较关键词词云。
- **沉默解码器**：切换群组，加入或移除模拟搜索信号，观察待验证假设的优先级变化。
- **增长实验室**：比较干预方案、查看预设六角色商业红队辩论、调整购买率和成本假设，计算情景净贡献。
- **结果导出**：导出 Markdown 实验卡、PNG 或可打印 HTML；PDF 通过浏览器打印另存。

## 本地运行

直接用现代浏览器打开 `index.html` 即可，无须安装依赖或构建。也可以在本目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。剪贴板功能受浏览器安全上下文和权限限制，部署后的 HTTPS 页面更适合演示。

## 技术结构

`index.html` 包含全部 HTML、CSS、合成数据和 JavaScript，是完整可运行源码，不是仅有页面外观的导出件。

- 原生 HTML / CSS / JavaScript，无第三方运行依赖。
- 无后端、数据库、账号登录或 API 密钥。
- 数据与计算在浏览器本地完成；研究资料链接为外部参考，不是案例实证。
- `.nojekyll` 用于直接发布静态文件。

## 数据与评分边界

评论由模板和场景组合构造，购买阻力标签预先给定。评论数量、条件性表达率和群组汇总由代码计算，但原始样本和经营输入为人工设定。

**场景匹配分与搜索关联分是预设模拟指标**，并非规则模型推断或历史数据训练所得。当前优先级公式：

| 指标 | 不含搜索 | 含搜索 |
| --- | ---: | ---: |
| 表达量（按最大主题数量归一化） | 18% | 12% |
| 条件性购买表达率 | 36% | 27% |
| 场景匹配分（预设） | 46% | 37% |
| 搜索关联分（预设） | 0% | 24% |

权重属于演示用启发式设定。优先分不是购买概率、因果结论或转化提升预测；评论表达者也不能等同于未支付消费者。

商业测算以用户输入的购买率、毛利和成本假设计算情景结果，不是实际实验成效。真实产品需要获得授权的数据、进一步校准及随机对照实验。
